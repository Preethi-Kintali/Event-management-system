## Executive Overview
This document consolidates all 14 official UML 2.5 diagram types categorized into **Structural Diagrams** (7) and **Behavioral Diagrams** (7).

### Part I: Structural Diagrams
1. **Class Diagram**: Core domain entities (User, Organization, Event, Team, Submission, Evaluation, Certificate).
2. **Object Diagram**: Runtime snapshot of active competition state.
3. **Component Diagram**: Modular presentation, security perimeter, domain services, and persistence components.
4. **Composite Structure Diagram**: Internal classifier architecture of the submission and evaluation engine.
5. **Deployment Diagram**: Physical nodes, execution environments, protocols, and deployed artifacts.
6. **Package Diagram**: Layered namespaces and unidirectional dependency flows.
7. **Profile Diagram**: Domain metamodel extension with custom stereotypes and tagged values.

### Part II: Behavioral Diagrams
8. **Use Case Diagram**: Stakeholder actors (Hackers, Coordinators, Managers, Judges) and system capabilities.
9. **Activity Diagram**: End-to-end hackathon workflow with fork/join concurrency and decision diamonds.
10. **State Machine Diagram**: Dual finite state automata for event lifecycles and submission pipelines.
11. **Sequence Diagram**: Temporal message lifelines for deliverable uploads and rubric evaluations.
12. **Communication Diagram**: Spatial object collaboration topology during attendee registrations.
13. **Timing Diagram**: Linear 48-hour event lifecycle state transitions and duration constraints.
14. **Interaction Overview Diagram**: Process control framing combining sequence diagram frames.
